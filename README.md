# $NIKO site

A scroll-driven 3D site for the $NIKO token. One fixed WebGL canvas plays a short film as you scroll: a man on a terrace over a neon city at dusk, a flight across the bay, a red office where an armchair turns to reveal him seated, then the token section.

Static files only. No build step, no framework, no package install.

## Run it

Serve the folder with any static server, for example:

```
python -m http.server 4173
```

Then open `http://localhost:4173`. Opening `index.html` straight from disk will not work, because the models are fetched.

## What is where

| Path | What it is |
|---|---|
| `index.html` | Markup, page text, loader markup, head tags |
| `css/styles.css` | All styles: tokens, overlay text, loader, token section, scroll cue |
| `js/main.js` | Renderer, scroll to film time, terrace and office sets, camera keys, frame loop |
| `js/vice.js` | The city: sky, towers, strip, port, water reflection, palms and cars |
| `js/niko.js` | Loads the two character models and picks the desktop or phone file |
| `js/post.js` | Post-processing (bloom, tone mapping, sharpen) and the resolution governor |
| `js/loader.js` | Loading screen, driven by real download progress |
| `vendor/` | Three.js r149 and its GLTFLoader |
| `models/niko/` | Character models (see sizes below) |
| `models/hd/`, `models/cars/`, `models/palms/`, `models/armchair/`, `models/bust/` | Props |
| `img/load/` | Loading-screen art |
| `vercel.json` | Cache headers for Vercel |

Page text fades with the film through `data-cue="a,b"` attributes, read in `main.js`.

## URL switches for review

| Switch | Effect |
|---|---|
| `?t=2.6` | Freeze the film at that moment (0 to 3) and skip the loader |
| `?q=1` | Force full render quality (turns the resolution governor off) |
| `?hq=1` | Load the lighter seated model (4K textures) |
| `?loadtest=1` | Play a simulated load so the loading screen can be watched |
| `?post=0` | Turn post-processing off |

## Size

The character models are shipped at full quality on desktop on purpose, so the page is heavy. Please do not decimate or re-encode them without checking first: an earlier attempt broke triangles on the face.

| What | Size |
|---|---|
| Whole repo | about 200 MB |
| A desktop visit downloads | about 94 MB |
| A phone visit downloads | about 35 MB |

Largest files, all in `models/niko/`:

| File | Size | Loaded when |
|---|---|---|
| `seat_full.glb` | 68.5 MB | desktop, by default |
| `stand_full.glb` | 28.9 MB | only with `?hq=1` |
| `seat_hq.glb` | 26.3 MB | `?hq=1`, or a GPU that cannot take an 8K texture |
| `stand_v3.glb` | 12.0 MB | desktop, by default |
| `seat_v3_m.glb` | 11.7 MB | phones |
| `stand_v3_m.glb` | 9.4 MB | phones |
| `seat_pro*.glb`, `stand_pro*.glb`, `seat.glb`, `stand.glb` | about 26 MB together | fallbacks if a file above fails |

Which set loads is decided in `js/niko.js` from pointer type and screen size. It deliberately does not use `navigator.deviceMemory`, which some browsers randomise.

## Deploying

Any static host works. `vercel.json` sets long cache lifetimes for models, images and vendor files and none for `index.html`. Model URLs carry a `?v=` tag in `js/niko.js`, and the scripts and stylesheet carry one in `index.html`; bump the tag when a file changes.

File names are case-sensitive on most hosts.

## Known gaps

- In the wider office shots the seated man looks slightly past the camera.
- A faint dark strip under the horizon late in the flight (film time about 1.8 to 2.0).
- Frame rate has not been measured on real phones.
- The loader is skipped under `prefers-reduced-motion`, and the film is replaced by the static page.
